# v0.9.4-alpha hardware validation

Release: **[v0.9.4-alpha](https://github.com/ChrisKariofyllis/LapGuard/releases/tag/v0.9.4-alpha)** (prerelease).

Target machines:

| Machine | OS | Battery | Naming | Power | Thresholds | Status |
| --- | --- | --- | --- | --- | --- | --- |
| Fujitsu Lifebook A3510 | this session: Ubuntu 26.04, kernel 7.0.0-14-generic | BAT1 | `charge_*` | derived `current_now × voltage_now` | none (`fujitsu_laptop`, TLP cannot set) | **validated** 18 Aug 2026 with published amd64 binary |
| Gigabyte Aero 16 | Zorin OS (expected) | BAT1 | `charge_*` | derived `current_now × voltage_now` | none on previously verified machine | **not run this session** |

Do **not** set `actions.real_enabled=true` or `safety.dry_run=false`. Do **not** run host `poweroff`, `shutdown`, `reboot`, `sync`, or `docker stop`. Automatic low-battery shutdown is not executed.

There is **no** `--version` / `-version` flag. Extra args are ignored and the process starts the daemon. Read version from `GET /api/v1/healthz`.

Release artifacts are **not** named `lapguard-linux-amd64`. Use:

- `lapguard_0.9.4-alpha_linux-amd64`
- `lapguard_0.9.4-alpha_linux-arm64`
- `SHA256SUMS`

POST routes require `Content-Type: application/json`. A bare `curl -X POST` without that header returns **415**, not 409. Poweroff/docker-drain also need `{"confirm":"POWER_OFF"}` / `{"confirm":"STOP_DOCKER"}`.

Prefer a **temp config** so this test does not rewrite `~/.config/lapguard/config.json`. Stop the PID you started; do not `killall`.

## 1. Download and verify

```bash
VER=0.9.4-alpha
BASE=https://github.com/ChrisKariofyllis/LapGuard/releases/download/v${VER}
wget "$BASE/lapguard_${VER}_linux-amd64" "$BASE/SHA256SUMS"
sha256sum -c SHA256SUMS --ignore-missing
chmod +x "lapguard_${VER}_linux-amd64"
./lapguard_${VER}_linux-amd64 -h 2>&1 | head -5
# expect: no -version flag
```

- [ ] amd64 checksum OK
- [ ] arm64 checksum OK (if that architecture)

## 2. Isolated daemon

```bash
BIN=./lapguard_0.9.4-alpha_linux-amd64
WORKDIR=$(mktemp -d)
port=$(python3 -c 'import socket; s=socket.socket(); s.bind(("127.0.0.1", 0)); print(s.getsockname()[1]); s.close()')
"$BIN" -web-dir none -listen "127.0.0.1:${port}" \
  -config "$WORKDIR/config.json" -events-db "$WORKDIR/events.db" &
pid=$!
URL=http://127.0.0.1:${port}
sleep 2
curl -sS "$URL/api/v1/healthz"
# stop later: kill "$pid"
```

Expect `healthz`: `"status":"ok"`, `"version":"0.9.4-alpha"`, `"auth_enabled":false`.

### Read-only API

```bash
curl -sS "$URL/api/v1/telemetry"
curl -sS "$URL/api/v1/power"
curl -sS "$URL/api/v1/actions/status"
curl -sS "$URL/api/v1/actions/preflight"
curl -sS "$URL/api/v1/safety"
curl -sS "$URL/api/v1/capabilities"
```

Expect:

- `actions/status`: `real_enabled=false`, `safety_dry_run=true`, `executor=recording`, `commands_executed=false`, `ready=false`, gates include `real_actions_disabled` and `safety_dry_run`, `config.reload=restart_required_for_disk_edits`
- `actions/preflight`: `commands_executed=false` and the disk-edit restart explanation
- Listen address remains loopback (do not bind `0.0.0.0`)

## 3. Tailscale CLI (no daemon)

```bash
./lapguard_0.9.4-alpha_linux-amd64 tailscale
./lapguard_0.9.4-alpha_linux-amd64 tailscale instructions
./lapguard_0.9.4-alpha_linux-amd64 tailscale check
```

Expect: usage on no subcommand (exit 1); instructions text (exit 0); JSON `lapguard_listen=127.0.0.1:8585`, `recommended_access=tailscale_serve`. Must **not** log `starting lapguard`.

## 4. Safety gates (dry-run)

```bash
# 415 without JSON
curl -sS -o /tmp/lg-nojson.json -w "%{http_code}\n" -X POST "$URL/api/v1/actions/poweroff"

# 409 with confirm; commands_executed must stay false
curl -sS -H 'Content-Type: application/json' -d '{"confirm":"POWER_OFF"}' \
  "$URL/api/v1/actions/poweroff"
curl -sS -H 'Content-Type: application/json' -d '{"confirm":"STOP_DOCKER"}' \
  "$URL/api/v1/actions/docker-drain"
```

Expect HTTP **409**, `"ok":false`, `"commands_executed":false`, `"error":"real actions are disabled"`. Host must not power off.

## 5. Notifications

```bash
curl -sS -H 'Content-Type: application/json' -d '{}' \
  "$URL/api/v1/actions/test-notification"
```

If unconfigured: HTTP **400** `"notifications are disabled"`. If ntfy/Telegram/Discord is enabled, test with `dry_run=true` first (see [alpha-testing.md](alpha-testing.md)).

## 6. Stop

```bash
kill "$pid"
wait "$pid" 2>/dev/null || true
```

Do not `killall lapguard-linux-amd64` (wrong binary name; may kill an unrelated process).
